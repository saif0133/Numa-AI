What reaches this team

  1. Sample requests a human reviewer chooses to hand off.

Proposed human review protocol

  1. Try the treating clinician again.
  2. Contact the patient's emergency contact if one is on file.
  3. If there is immediate danger, call emergency services: 911 in Jordan, 999 or 998 in the UAE.
  4. Production requires verified access controls and audit records. This demo only records sample actions.
